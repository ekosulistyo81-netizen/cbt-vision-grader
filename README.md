# Vocational Auto-Grader (Vision AI)

A lightweight, open-source pipeline built for vocational schools (SMK) in Indonesia to automate the grading process. This tool uses Vision LLMs to accurately extract handwritten assessment scores from physical paper forms (like PKL validations) and directly injects the parsed data into an automated Excel gradebook template.

Built to eliminate redundant administrative overhead for independent teachers without relying on expensive enterprise software.
